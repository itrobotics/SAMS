學生到校管理系統 — 使用者操作指南

版本 v1.0 2026-04-28 適用：HQ Admin / Branch Admin / Teacher / Staff

系統概覽

ICE SAMS 是一套多分校補習班學生到校管理系統，功能類似診所報到系統：學生到校後完成報到，老師與總部即時看到誰到了、誰沒來、誰請假。

主要作業流程

排課設定
→
每日產生場次
→
建立應到名單
→
學生到校報到
→
更新出席狀態
→
Dashboard 即時顯示

角色與權限

系統依職責分為四種角色，登入後自動套用對應權限。

👑
HQ Admin
總部管理員。可看所有分校資料、建立分校、管理使用者帳號。
🏫
Branch Admin
分校管理員。只能看到所屬分校，可管理學生、班級、出席。
📚
Teacher
老師。只能看到自己負責的班級與出席記錄。
🖥️
Staff
行政人員。可執行報到、協助處理請假，但不可修改課程設定。

新增分校步驟

1

2
填入分校 ID
用英文小寫，不可含空格（例：anhe, dazhi），建立後無法更改。

4
儲存
點「儲存」完成，分校立即出現在列表中。

產生今日場次

「場次」是每天課程的實例，系統需要先產生場次，才能開始記錄到班。正式上線後系統每日凌晨自動產生；目前可在設定頁手動觸發。

每天第一次使用前，請先到「設定」頁點一次「產生今日場次」，確保今日課程已建立。

操作說明

按鈕說明
已到標記學生已到，時間記錄為按下按鈕的時間。若在遲到時間之後，系統自動標記為「遲到」。
請假標記為請假，不列入缺席統計。
未到明確標記缺席（通常不用手動設，未報到預設即為未到）。
重設清除目前狀態，恢復為「未到」，可重新操作。
狀態一旦修改，Dashboard 上的統計數字會即時更新。請謹慎操作，確認後再按。

出席狀態說明

狀態說明
已到準時報到（在遲到門檻時間前）
遲到課程開始超過 N 分鐘後才報到（預設 15 分鐘）
請假事先登錄請假
未到課程期間未報到
缺席課程結束後仍未報到（系統自動轉為缺席）
